# khon_shell
Ramakien-inspired Arch Linux dotfiles and themes for Quickshell

Hello everyone, I am actively designing the dotfiles for this repo so I wouldn't count this working for you (yet).
I will continue to develop this over time; I am using this as a fun way to learn how to code.
This config theme will use artwork based on the Ramakien, Khon, as well as other Thai and Lao cultural references.
